# Trạng thái GitHub

Repository riêng tư: https://github.com/duongtanminh1912/it3180-202416560-aims

CLI đã xác thực. Chưa có partner được chỉ định; không tự mời collaborator, không tự approve. Luồng Request changes → sửa → re-request → Approve chưa thực hiện. Branch protection, CI, các PR và Release tiếp theo sẽ được kiểm tra trong đúng bài; không coi là hoàn thành trước khi có bằng chứng.
